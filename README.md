# 🤖 AI Knowledge Assistant

An AI-powered PDF chatbot that allows users to upload PDF documents and ask questions in natural language using Retrieval-Augmented Generation (RAG).

## 📌 Features

* 📄 Upload PDF documents
* 🔍 Semantic search using FAISS
* 🧠 Retrieval-Augmented Generation (RAG)
* ⚡ Fast responses with Groq Llama 3
* 💬 ChatGPT-style conversational interface
* 🎨 Modern cyberpunk-themed UI
* ☁️ Deployed on Streamlit Cloud

---

## 🛠️ Tech Stack

* Python
* Streamlit
* LangChain
* FAISS
* Sentence Transformers
* Groq API
* Llama 3
* HuggingFace Embeddings

---

## 📂 Project Workflow

1. Upload a PDF document
2. Extract text from the PDF
3. Split text into chunks
4. Generate embeddings
5. Store embeddings in FAISS vector database
6. Retrieve relevant chunks based on user queries
7. Generate answers using Groq Llama 3
